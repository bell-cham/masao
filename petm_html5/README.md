# ペットモンスター 基本セット HTML5移植版

添付 `petm_kset.zip` に内包される `petm_c.zip`（2003年5月29日版）を移植したゲームです。
11クラス、332フィールド、137通常メソッド、11コンストラクターを対応させています。
ゲームロジックは元クラスからJavaScriptへ変換し、Applet/AWT・スレッド部分をブラウザ用互換層へ置き換えています。

## 起動

ZIPを展開し、`game/index.html` をブラウザで開いてください。画像・JavaScript・フォントはすべて同梱され、実行時の外部サービス、Java、Node.js、ビルド処理は不要です。

起動ページ：

| ページ | モード |
|---|---|
| `index.html` | オリジナルゲーム |
| `index_con.html` | コンストラクション |
| `index_rr.html` | ラギアス爆誕 |

一般的な静的Webサーバーでは `game/` の中身を同じ階層関係のまま配置します。
ローカルサーバーを使う場合は、`game/` を作業フォルダーとして `python -m http.server 8000` を実行し、`http://localhost:8000/` を開けます。
ブラウザのローカルファイル制限によりフォントが読み込めない場合は、このローカルサーバー方式を使用してください。

## 操作

画面をクリックするとゲームにフォーカスが移ります。

| キー | 原作の操作 |
|---|---|
| ← / テンキー4 | 左 |
| → / テンキー6 | 右 |
| ↑ / テンキー8 | 上・選択 |
| ↓ / テンキー2 | 下・選択 |
| Z / Space | 決定・ジャンプ |
| X | キャンセル |
| C | 原作の第3トリガー |
| S | 原作のスタートフラグ |
| J | ペットへジャンプ命令 |
| T | タイトルへ戻る |
| マウス押下 | タイトル開始等、原作のマウス入力 |

矢印キーとSpaceのページスクロールを防ぎます。テンキー操作はNumLockをオンにしてください。
入力フラグと継続押下のカウンターは元の `GameKey` と各ゲームメソッドで処理します。

## 設定変更

各起動HTMLの `<div id="game-params" hidden>` にある `<param name="…" value="…">` を編集します。
すべてのページが同じJavaScriptを使用し、読み込み時にPARAMの値を取得します。マップ、名前、会話、画像ファイル名等は元HTMLを基にしています。`index.html` の文字化けは正常な正規HTMLとの照合と誤変換の再現一致を確認して修復しました。
`0` を数値として解釈できる会話行を除外する処理、未指定数値PARAMを `-1` とする処理等は原作メソッドのままです。

`system_mode` の変換も原作通りです。

| HTMLの値 | 内部モード |
|---|---|
| 1 | 1 |
| 2 | 3 |
| その他（0・3・未指定等） | 0 |

内部モード2向けの分岐も削除せず移植しています。ただし、この原本の初期化処理は内部モード2を選択しません。上級版という別モードや起動ページは新設していません。

## 構成

- `game/`：静的配信・ローカル実行用のゲーム本体。
- `game/js/*.js`：11クラスの全移植コード、互換層 `platform.js`、初期化 `boot.js`。
- `original/`：添付ZIPを展開した原データ（`g*.html` は資料としてのみ保存）。
- `analysis/java/`：逆コンパイルしたJava参照コード。
- `analysis/JAVA-JS-MAPPING.md`：全メソッド・全フィールドの対応表。
- `analysis/params.json`：正規HTML3ページの全PARAM値。
- `analysis/class-inventory.json`：原クラスのハッシュと件数。
- `analysis/VALIDATION.md`：確認内容、結果、検証の限界。
- `analysis/KNOWN-ISSUES.md`：原作由来の注意点と互換差。
- `analysis/BUG-CHANGES.md`：原作のバグ変更の有無。
- `tools/`：変換・解析・Java対照実行・ブラウザ検証用スクリプト。

## 描画・演算

内部画面は512×320、スプライトは32×32、原作更新間隔は70msです。Canvasの拡大表示では補間を無効にしています。
整数除算のゼロ方向への丸め、32bit整数演算、short/byte/char変換、配列境界、Java Randomの48bit乱数を互換層で扱います。
原作の描画順、スクロールバッファ、左右反転・白いマスク、施設・戦闘・パスワード・図鑑・エンディングの分岐を保持しています。
ブラウザでフォーカスを失うと押下状態を解除します。背景タブから戻った際に長時間分の更新を連続実行しません。

日本語システムフォントがない環境向けにNoto Sans JPのサブセットを同梱しています。原作素材は変更していません。フォントの条件は `FONT-LICENSE.txt` に記載しています。

## 検証の再実行

検証にはJava 17のJDK、Pythonと `javalang==0.13.0`、Node.js、Playwright、Chromiumが必要です。ゲームのプレイには不要です。
`tools/browser.cjs` のChromiumのパスは `CHROMIUM_PATH` で指定できます。Playwrightモジュールの読み込み先は利用環境に合わせて変更してください。

逆コンパイルにはCFR 0.152を使用しました。`MainProgram.mapsMakeStageData` のshort配列への格納1箇所は、逆コンパイル結果に不足していた明示的shortキャストを補っています。これはJVMの `sastore` が行う型変換を示すもので、ゲームルールの修正ではありません。

検証結果は、実施したテスト範囲を示すものです。全ルートを人の操作で開始からクリアまで通したという意味ではありません。

## HTML修復版

2026年10月8日：オリジナルゲームの文字化けした85個のPARAM値とタイトル・コメント・操作説明・作者リンクの日本語を修復しました。3ページとも元のhead/body、中央配置、512×320の表示寸法、操作説明と作者リンクを保持しています。AppletをCanvasと非表示PARAM領域に置き換え、UTF-8宣言と必要なJavaScriptのみを追加しています。前版の追加ナビゲーションと1.5倍拡大のレイアウトは取り除きました。

添付時の `original/` は比較用の原本として変更していません。修復済みの起動HTMLは `game/` にあります。復元した原形式の `index.html` は `analysis/restored-index.html`、変更したPARAMの一覧は `analysis/HTML-REPAIR-CHANGES.json` にあります。
