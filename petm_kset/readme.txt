[ 内容について ]

このゲームは、 InternetExplorer5.5 以上で動作する JavaApplet です。


[ ゲームで遊ぶ ]

オリジナルゲームの場合は、
 index.html をダブルクリックするなどして、ブラウザで実行して下さい。
マップ作成機能のあるコンストラクション版、ボス戦対応のラギアス爆誕は、
 index_con.html 、 index_rr.html を実行して下さい。


[ グラフィックの変更] 

以下の *.gif ファイルを、描き変えて下さい。

title.gif         タイトル画面
title_rr.gif      タイトル画面         ラギアス爆誕用
gameover.gif      ゲームオーバー画面
ending.gif        エンディング画面
ending_rr.gif     エンディング画面     ラギアス爆誕用
chizu.gif         地図画面の背景
chizu_rr.gif      地図画面の背景       ラギアス爆誕用
gym.gif           ジム戦の背景
pattern.gif       キャラクターなどのパターン


[ ゲーム内容の変更 ]

 index_con.html には、マップ作成機能などがあります。
メモ帳などで開き、 PARAM タグにある "" 内の文字を変更します。
詳しくは、そちらを見て下さい。


[ ゲームの公開 ]

 Web 上で動く JavaApplet として、グラフィック、マップ、
ＨＴＭＬ部分を改造したゲームを公開する事は、自由で、許可不要です。
ここで使われたファイルを全て、サーバーの同じフォルダに、
アップロードして下さい。
