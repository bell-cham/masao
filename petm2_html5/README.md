# ペットモン２ JavaScript全量移植版

ZIPを展開し、HTTPサーバーでこのフォルダーを公開して、`index.html`を開いてください。
Pythonがある場合は、このフォルダーで次を実行できます。

```sh
python -m http.server 8000
```

ブラウザで `http://localhost:8000/index.html` を開きます。
プレイ中にJava、Javaプラグイン、CheerpJ、WebAssembly、外部CDNは使用しません。

## 起動ページ

| ファイル | 内容 |
| --- | --- |
| index.html | 基本セット |
| index2.html | 上級編 |
| index_con.html | コンストラクション版 |
| index_kodai.html | 古代の大怪獣 |
| index_shiai.html | 試合観戦 |
| index_shiai2.html | 試合観戦・別画像セット |
| index_race.html | ペットレース ミニ |

操作説明と文言は各起動ページに元の内容を残しています。
基本操作は方向キー、Z／スペースで決定、Xでキャンセル、Cで主人公のジャンプ、Tでタイトルに戻る、です。
その他のキー、技やペットの選択方法は起動ページの操作説明をご覧ください。
パスワードの表示と入力はブラウザのダイアログで行います。コピーと貼り付けができます。

## 移植の構成

`petm2_kset.zip`として提供された原本一式内の`petm2_c.zip`を基準に、12クラス、183メソッド、355フィールドを対応させています。
ゲーム処理は`js/`内の同名クラスに移植しています。オーバーロードの識別に`メソッド名$引数の数`を使用しています。
画面別のゲーム再実装は行っていません。各`index*.html`の有効なPARAM、画像、マップ、会話、パスワード処理、技、施設、戦闘、図鑑、大会、レース、終了処理を保持しています。
`g*.html`は移植元に使用していません。`index_shiai2.html`が元から使用している`g.gif`等の画像は保持しています。

`platform.js`がApplet/AWTの描画・画像・入力・ダイアログをブラウザAPIへ接続し、`boot.js`が元の70ms周期の処理を実行します。
整数除算、整数の符号、短整数・文字コード変換、浮動小数点変換、乱数の計算方式を原作に合わせています。
戦闘の`mMove`は原本の5,780命令に対応するJavaScriptの分岐へ変換しました。実行時にクラスファイルや命令データを読み込む方式ではありません。
原作の座標、フォントサイズ、色、画像を使用します。文字のラスタライズはブラウザとOSが担当します。

## 検証結果

- 12/12クラス、183/183メソッド、355/355フィールドを静的検査・ブラウザ上の存在検査で確認。
- 7ページの有効なPARAM、合計1,423項目の値を照合。
- 同梱する原本の画像等はバイト単位で一致。
- 元のJavaクラスを検証時のみ実行し、生成・能力・パスワード・マップ・攻撃処理の863ケースでJavaScript版と結果が一致。
- 7ページの起動、性別・名前選択、最初のペット入手、マップ移動、ステージ進入と戦闘、施設の利用、ジム戦、試合観戦、レースの結果表示、パスワードダイアログ、図鑑、ゲームオーバー・エンディング表示をブラウザで確認。

詳細は`validation/`の検査表、シナリオ記録、スクリーンショットをご覧ください。
183/183は移植対応・存在の確認です。全183メソッドの全分岐を実機で網羅したという意味ではありません。
施設や終了画面等の一部の確認では、入口位置・ゲーム状態を検証用に設定しています。シナリオ記録で区別しています。
